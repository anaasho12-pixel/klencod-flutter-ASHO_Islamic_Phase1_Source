# ASHO – أشو الإسلامية

Flutter Android starter for an offline-first Islamic companion app.

## Requirements
- Flutter stable (Dart 3.4+)
- Android Studio / Android SDK
- A connected Android device or emulator

## Run
```bash
flutter doctor
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter analyze
flutter test
flutter run
```

## Android package identifier
The intended Android application ID is `com.asho.islamic`.
After creating the Flutter project, verify `android/app/build.gradle` (or
`build.gradle.kts`) uses this applicationId/namespace. If the Android folder
was generated by Flutter with a different ID, update it there.

## Included in this starter
- Arabic RTL-first dashboard and emerald/gold visual theme
- Light/dark theme toggle
- Local SQLite database using Drift
- Persistent quick tasbeeh counter
- Local notes CRUD repository foundation
- Bookmark, reading progress, adhkar, favorites, audio progress,
  prayer settings, khatma and downloaded-file tables
- Basic widget and database tests

## Important content policy
No Quran verses, hadith, prayer times, or adhkar are fabricated or seeded.
Verified religious content and licensed audio should be added only after
source review and rights checks.

## Scope
This is Phase 1 foundation code, not a complete Quran/audio/prayer product.
Prayer calculations, Qibla sensors, Quran text/audio datasets, notifications,
backup/restore UI and full localization are planned for later phases.
